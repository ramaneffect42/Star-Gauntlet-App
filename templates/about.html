About Model & Astrophysical Principles

Academic documentation, machine learning architecture, and stellar classification physics for college evaluation and defense.

Machine Learning Architecture Production Pipeline
Algorithm: Random Forest Classifier (100 Decision Trees)
Learning Paradigm: Supervised Multi-Class Classification
Ensemble Method: Bootstrap Aggregating (Bagging) with random feature subspace sampling
Input Dimension: 6 stellar features (4 continuous numerical + 2 categorical)
Output Space: 6 discrete stellar taxonomy classes (Brown Dwarf to Hypergiant)
Pre-processing Pipeline: Scikit-learn ColumnTransformer with StandardScaler for numerical attributes and OneHotEncoder(handle_unknown='ignore') for categorical attributes.
Evaluation Split: 80% Training (192 stars) / 20% Testing (48 stars), Stratified.
Algorithm Explanation for Presentation Viva-Ready
"Random Forest combines predictions from multiple decision trees. Each tree analyzes the input features independently on a random bootstrap sample, and the combined majority vote (and average class probability) determines the final predicted star type."

Why Random Forest for this problem?

  • Handles severe non-linear physical relationships across stellar regimes.
  • Provides built-in resistance to overfitting on tabular astronomy data.
  • Generates mathematically rigorous class probabilities via predict_proba().
  • Provides explicit Gini impurity feature importance ranking.
